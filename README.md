- 📅 مسوسیکل ۴ هفته‌ای: هفته اول دلود، RIR ثابت بر اساس نوع حرکت
- 📊 داشبورد حجم: ست هفتگی هر عضله در برابر هدف (با شمارش غیرمستقیم)
- ⚠️ هشدار جهش بار (ACWR) و علائم ریکاوری
- 🔁 بازنگری پایان بلوک: هیچ / حجم± / تعویض — پیشنهاد سیستم بر اساس لاگ
- 🎥 ویدیوی فرم صحیح هر حرکت
